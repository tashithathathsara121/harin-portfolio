# Harin Ruwanpathirana — Executive Portfolio

A responsive React + Vite portfolio using Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js 18+.
2. Open this folder in VS Code and open its terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal (usually http://localhost:5173).

## Production

Run `npm run build`; deploy the generated `dist/` directory to a static host.

## Customization

- Edit personal information and page sections in `src/App.jsx`.
- Edit colors and layout in `src/styles.css`.
- Theme toggle is saved in localStorage.
- No real portrait or contact details were provided, so the hero uses a custom typographic identity and the contact section deliberately contains no fabricated links or email address.
- "Skills" highlights factual professional and academic background rather than claiming unverified technical competencies.
